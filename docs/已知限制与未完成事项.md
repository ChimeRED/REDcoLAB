# REDcoLAB 已知限制与未完成事项

- 版本：1.0.0
- 更新时间：2026-10-15
- **本文件的作用：明确区分「已完成」「待真机验证」「不可行」，不允许含糊。**

---

## A. 当前技术路线不可行（已终止，不找替代品）

### A-1 功能 A：CSP 原生导航器实时投影 —— 不可行

**需求**：在 CSP 原生导航器上扩展，做低开销的实时画布投影。

**结论**：**当前技术路线无法实现，暂停开发。**

**依据（真实 SDK 头文件 + 官方文档）**：

1. 官方 SDK 只能产出**滤镜插件**。许可契约书第 1 条把插件定义死为「给 PAINT EX 追加滤镜功能」。
2. 核对真实头文件 `sdk_official/TriglavPlugInRecord.h` 的 `TriglavPlugInRecordSuite`：
   全部可用能力只有 moduleInitialize / filterInitialize / filterRun 三组，**没有任何导航器、视图、画布变化通知接口**。
3. 滤镜的调用时机是「用户执行滤镜命令」那一次，处理对象是宿主交来的图层像素 —— **不存在事件驱动的更新来源**。
4. CSP 主程序二进制内找不到任何与第三方导航器扩展相关的入口。

**明确未做的事**：

- **没有写任何屏幕截图 / 桌面捕获 / 窗口捕获 / 录屏 / 定时截屏轮询代码。**
- 没有用独立预览窗口冒充导航器扩展。
- 没有读 CSP 内存或调用非公开接口。

> 旧版 v0.1.6 曾用「10-60fps 抓屏 + 置顶窗口」实现过类似效果。该实现**已被整块移除**，因为屏幕抓取是本项目明令禁止的手段。见 `_baseline/legacy-v0.1.6/BASELINE-README.md`。

### A-2 功能 C：独立叠加剪切蒙版 —— 不可行

**需求**：在原生「用下一个图层剪切到图层」之外，建立 REDcoLAB 自己的嵌套剪切关系。

**结论**：**不可行，未开发。**

**依据**：SDK 中与「图层」相关的 proc **只有一个** `getLayerOriginProc`（取当前处理图层的原点坐标）。
不存在图层枚举、图层树、蒙版读写、剪切关系读写、图层增删通知。

**明确未做的事**：没有用普通文件夹、图层合并、静态复制或预烘焙图像冒充「独立的运行时嵌套剪切关系」。

### A-3 常驻停靠面板 —— 不可行

SDK 只提供滤镜自己的模态对话框，没有面板宿主接口。**不会把普通窗口冒充成原生停靠面板。**

### A-4 插件注册快捷键 —— 不可行

SDK 无此接口。快捷键只能由 CSP 自身的「快捷键设置」分配给滤镜。

## B. 已实现但尚未完成真实软件验证（关键，必须验证）

### B-1 CSP 是否加载本插件 —— **最高优先级未验证项**

**已确证的进展（2026-10-16）**：

**位置 [1] `%APPDATA%\CELSYSUserData\CELSYS\CLIPStudioPlugIn\PAINT` —— 实测不被加载。**

- 装好三个文件（SHA256 逐一核对与源一致）→ 清干净日志 → 用户在 **13:11:49** 启动过 CSP
  （证据：`ApplicationRestoringState.sqlite`、`RecentFiles\recentfiles` 于 13:11:51 被写入）
- **用户 `%TEMP%` 中始终没有 `REDcoLAB_probe.log`**
- 探针在 `DllMain` 的 `DLL_PROCESS_ATTACH` 就**无条件**写日志 ⇒ 只要 DLL 被映射进进程就必然有日志
  ⇒ 日志不存在 = **CSP 根本没打开这个文件**

  **这推翻了旧版 v0.1.6 的核心假设**：旧版装到 `CLIPStudioModule\PlugIn\PAINT\win`，
  与位置 [1] 同属「用户数据目录」一类，很可能同样不被扫描 —— 这解释了它为什么「装了没用」。

**当前正在验证**：位置 [6] CSP 程序目录 `PlugIn\PAINT`（Celsys 自带 40 个滤镜同处），
探针已放入，等待一次重启结果。

## E. 许可与分发限制（重要）

【官方契约书】CELSYS SDK 使用许可的要点：

- 许可范围：开发 + **自己使用**；要把插件提供给他人，必须**按 Celsys 指定方式提交并经其确认**（第 4 条、第 8 条第 6 项）。
- 不得用 SDK 开发「独自或派生的开发工具」再分发（第 8 条第 1 项）。
- **SDK 头文件著作权属 CELSYS**；源码公开时**不得包含头文件**（第 5 条、第 11 条）。

**本项目的应对**：

- `sdk_official/` 与 `reference/` 已 gitignore，**不在仓库、不在归档包、不在 Release 附件**。
- 构建脚本在缺少 SDK 头文件时**明确失败并指向 CELSYS 官方下载页**，不会去第三方镜像拉取。
- 归档脚本在打包后**扫描包内容**，出现 `TriglavPlugIn*.h` 即中止。
- **推送/发布前需要你确认**，因为这会替换 GitHub 上的现有版本。

## F. 与旧版 v0.1.6 的差异（旧新对照）

| 项 | 旧版 v0.1.6 | 新版 1.0.0 | 原因 |
|---|---|---|---|
| 灰度滤镜 | 有，可用 | 有，重写并加固 | 保留有效设计，补齐健壮性 |
| 宿主回调判空 | 未判空 | 全部判空 + 安全默认值 | 旧版遇到缺失回调会崩溃（已实测复现） |
| 屏幕抓取导航器 | 有（10-60fps 抓屏） | **移除** | 明令禁止 |
| Python 伴侣程序 / 全局热键 / 常驻设置面板 | 有 | **移除** | SDK 无常驻面板接口，不得用普通窗口冒充 |
| SDK 头文件获取 | 从第三方 GitHub 镜像拉取 | **改为只从 CELSYS 官方页面获取** | 合规性 |
| 产物 | 仅 `.cpm` | `.cpm` + `.dll` | 实测发现 `.cpm` 字面量不在 CSP 二进制中 |
| 安装位置 | 单一目录 `CLIPStudioModule\PlugIn\PAINT\win` | 全部候选目录 + 打印路径 | 旧版的加载位置从未被验证 |
| 声明口径 | README 宣称「已装进 CSP」 | 明确区分「模拟 PASS」与「待真机验证」 | 旧版声明了未验证的结论 |
| 编码坑 | 未记录 | 已记录并写入规则 | PS 5.1 按 ANSI 读 UTF-8 会破坏解析 |
