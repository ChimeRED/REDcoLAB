# REDcoLAB 1.0.0 发布说明

> 本文件由 `tools/archive.ps1` 在创建 GitHub Release 时作为发布说明使用。
> 每次发版前更新。

---

## 红红子LAB / REDcoLAB 1.0.0

Clip Studio Paint **5.0 EX** 原生滤镜插件（CELSYS Triglav Plug-In SDK，C++17 / MinGW-w64）。

**本版为完全重建，替换此前的 v0.1.6。** 按官方 SDK 的真实能力重新实现，不继承未经验证的假设。

---

### 已实现并通过自动化测试

- **一键灰度**：8 种算法（Rec.709 加权 / Rec.601 加权 / 平均值 / 明度最大 / 明度最小 / 单通道 红绿蓝）
- **强度滑块** 0-100，与灰度结果线性混合
- CSP 自绘参数面板（与「工具属性」同一套 UI），支持**实时预览**
- 支持**选区**与羽化边缘平滑过渡
- **不修改 Alpha**、跳过完全透明像素（逐像素断言验证）
- 只登记栅格图层类型（RGB / 灰度 / 二值化灰阶），其余由宿主自动从可执行范围排除

### 相对旧版 v0.1.6 的移除项（重要）

- **移除屏幕抓取导航器**。旧版用 10-60fps 抓屏 + 置顶窗口实现「实时导航图」。
  这属于明令禁止的手段，且 CSP 官方 SDK 不提供导航器或视图接口 —— 该功能不可行。
- **移除 Python 伴侣程序**（全局热键、常驻设置面板、开机自启）。
  SDK 无常驻面板接口，用普通窗口冒充原生停靠面板不被接受。
- **不再从第三方镜像获取 CELSYS 头文件**。SDK 头文件不入库、不打包
  （归档包已扫描确认无 SDK 材料）。

### 已终止的功能及依据

| 功能 | 依据 |
|---|---|
| 独立叠加剪切蒙版 | SDK 无图层枚举 / 图层树 / 蒙版接口。全部 SDK 中与图层相关的只有一个 `getLayerOriginProc` |
| 导航器实时投影 | SDK 无导航器、视图状态、画布变化通知接口 |
| 常驻停靠控制面板 | SDK 只提供滤镜自己的模态对话框 |
| 插件注册全局快捷键 | SDK 无此接口，只能由 CSP 的「快捷键设置」分配 |

### 健壮性

插件对宿主未提供的可选回调全部判空（执行阶段与初始化阶段均已覆盖），
缺失时安全降级或明确失败并记日志，**不会导致 CSP 崩溃**。
测试覆盖「正常宿主」与「最小宿主」两种契约。

### 安装

把 `REDcoLAB.dll`（以及 `REDcoLAB.cpm`）放到：

```
%APPDATA%\CELSYSUserData\CELSYS\CLIPStudioPlugIn\PAINT\
```

然后**完全退出并重启** Clip Studio Paint，在 `滤镜` 菜单中查找 `红红子LAB → 一键灰度`。

快捷键：`文件 → 快捷键设置 → 类别「滤镜」→ 红红子LAB / 一键灰度`。

### 尚未验证（如实声明）

**CSP 是否实际加载本插件仍待真机确认。** 模拟宿主全流程测试全部通过，
但真机加载需要一次重启验证。CSP 5.0.4 主程序内 `.cpm` 字面量出现 **0 次**，
因此同时提供 `.dll` 与 `.cpm` 两种形式以覆盖该不确定性。

### 运行日志

默认不写日志。排查问题时设置环境变量 `REDCOLAB_LOG=1` 后重启 CSP，
日志位于 `%TEMP%\REDcoLAB.log`。

### 许可

本仓库**不包含** CELSYS SDK 头文件或样例源码。依据 CELSYS SDK 使用许可契约书，
把插件提供给他人需按其指定流程提交并经确认；自己使用不受此限。
