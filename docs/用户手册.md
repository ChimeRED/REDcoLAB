# REDcoLAB 用户手册

- 项目：红红子LAB / REDcoLAB
- 适用软件：**Clip Studio Paint 5.0 EX**（Windows）
- 版本：1.0.0

---

## 1. 这个插件是什么

一个 CSP **原生滤镜插件**。装好后它出现在 CSP 自己的「滤镜」菜单里，点开后由 **CSP 自己绘制参数面板**（和「工具属性」是同一套界面），参数改动会**实时预览**在画布上。

它只做一件事：**把栅格图层的颜色变成灰度**，并且尽量不破坏你的数据。

---

## 2. 装好之后长什么样

```
滤镜(F) → 红红子LAB → 一键灰度
```

打开后参数面板有两个控件：

| 控件 | 类型 | 作用 |
|---|---|---|
| **灰度算法** | 下拉，8 个选项 | 用哪种公式算灰度值 |
| **强度** | 滑块 0-100 | 0 = 不变，100 = 完全灰度；中间值做线性混合 |

### 灰度算法说明

| 选项 | 公式 | 特点 |
|---|---|---|
| Rec.709 加权（默认） | 0.2126 R + 0.7152 G + 0.0722 B | 高清电视标准，最接近人眼亮度感受，插画最常用 |
| Rec.601 加权 | 0.299 R + 0.587 G + 0.114 B | 旧标清标准，绿权重略低，画面略亮 |
| 平均值 | (R+G+B)/3 | 最简单，高饱和色容易偏亮 |
| 明度最大 | max(R,G,B) | 保留高光，整体偏亮 |
| 明度最小 | min(R,G,B) | 保留暗部，整体偏暗 |
| 单通道 红 / 绿 / 蓝 | 取单个通道 | 提取单色信息，做通道分离时有用 |

---

## 3. 怎么用（一键灰度）

1. 在**图层面板选中一个栅格图层**（彩色或灰度都行）。
   - 可选：先画一个选区，则只在选区内生效，羽化边缘会平滑过渡。
2. `滤镜 → 红红子LAB → 一键灰度`
3. 默认就是「Rec.709 加权 + 强度 100」，**直接回车/确定**即完成。
4. 想微调：拖「强度」滑块，画布会实时预览；满意后确定。

### 撤销

走的是 CSP 自己的滤镜流程，所以 **Ctrl+Z 就能撤销**，和其他滤镜一样。

---

## 4. 绑定快捷键（做成真正的「一键」）

插件**不能自己注册快捷键**——这是官方 SDK 的限制，任何滤镜插件都做不到。但你可以让 CSP 帮你绑：

1. `文件 → 快捷键设置`
2. 类别选 **「滤镜」**
3. 找到 **红红子LAB / 一键灰度**
4. 设成比如 `Ctrl+Shift+G`

以后按这个键会直接唤出该滤镜（参数沿用上次的设置），回车确定即可。

## 5. 支持范围与不支持的对象

### 支持

- **栅格图层**（彩色 RGB 层、灰度层、二值化灰阶层）
- 带**选区**（含羽化边缘）
- **锁定透明像素**的图层（插件不修改 Alpha，所以锁定与否结果一致）
- **完全透明的像素**按设计**跳过**，不会被写入

### 不支持（这是官方 SDK 的限制，不是本插件偷懒）

| 对象 | 结果 | 原因 |
|---|---|---|
| 矢量图层 | **不会出现该滤镜** | 插件只登记接受栅格图层类型；CSP 会自行把不支持的图层从可执行范围里排除 |
| 文字图层 | **不会出现该滤镜** | 同上（文字不是栅格像素，需要先栅格化） |
| 文件夹（图层文件夹） | **不会出现该滤镜** | SDK 没有图层树接口，插件无法遍历或修改文件夹 |
| 3D 图层 / 图像素材图层 / 对白框 / 框线 | **不会出现该滤镜** | 同上 |
| CMYK 图层 | 执行但**不做任何修改**（安全退出） | SDK 未提供该通道排列的转换路径；此时会保持原样而不是写坏 |
| 已经是灰度的图层 | 执行但**不做任何修改** | 没有可转换的信息 |

> **关于「全部图层一键灰度」**：**做不到**。滤镜一次只作用于一个目标图层，官方 SDK 没有图层枚举接口。如果要对多图层处理，需要逐层执行，或者改用 CSP 原生的颜色模式/色调校正功能。
>
> 如果 CSP 里有同样效果的**原生方法**，优先用原生方法——它更稳定、可非破坏、撤销语义更清晰。

## 6. 数据安全说明

- **不修改 Alpha（透明度）**：只改 RGB 三个通道。已在自动化测试中客观验证（比较处理前后的 Alpha 数组完全一致）。
- **完全透明像素不写入**：`alpha == 0` 的像素直接跳过。
- **破坏性**：滤镜最终是**写回图层像素**。这是滤镜机制本身决定的，无法做成非破坏。
  - 想要非破坏：先 `图层 → 复制图层`，再在副本上执行；或者执行后用 Ctrl+Z 撤销。
- **不会静默失败**：不支持的通道排列会安全返回且不改动画布；不支持的图层类型根本不会出现在可执行范围里。

## 7. 已知限制（务必阅读）

1. **需要 CSP EX**。官方明文限制：滤镜插件只在 PAINT EX 上工作，PRO 版不支持。
2. **需要重启 CSP 才会加载**。插件是在启动时扫描的，装完必须**完全退出再启动**。
3. **「全部图层」不可能**（见上）。
4. **不能注册快捷键**（只能用 CSP 的快捷键设置分配）。
5. **没有常驻面板**。参数面板是滤镜自己的模态对话框，做不到像「工具属性」那样常驻停靠——官方 SDK 没有该接口。**本插件不会用独立窗口冒充原生面板。**
6. **本机加载路径仍在确认中**。CSP 5.0.4 的主程序里找不到 `.cpm` 这个字面量，所以「用 `.cpm` 扩展名装到哪个目录才会被加载」这件事**还没有在真机上验证成功过**。安装脚本会把产物同时放到所有候选目录，需要一次真机重启来确认。详见 `docs/测试报告.md`。

## 8. 出问题了怎么排查

### 滤镜菜单里找不到「红红子LAB」

1. 确认是 **EX** 版（PRO 不支持插件）。
2. 确认**完全退出并重启**了 CSP。
3. 确认产物真的在插件目录里：运行
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File tools\install_plugin.ps1
   ```
   看它列出的候选目录里有没有文件。
4. 打开诊断日志：设环境变量 `REDCOLAB_LOG=1` 后重启 CSP，日志写到 `%TEMP%\REDcoLAB.log`。
   - 如果日志里**什么都没有**，说明 CSP 根本没加载这个插件（问题在安装位置/扩展名）。
   - 如果日志里有 `[init]` 但没有 `[filterInit]`，说明加载了但注册滤镜失败。

### 点了确定但画面没变化

- 确认选中的是**栅格图层**。
- 确认「强度」不是 0。
- 确认没有在 CMYK 或已经是灰度的图层上执行（这两种情况按设计不改动）。

### 画面变灰了但我不想要

`Ctrl+Z` 撤销。

---

## 9. 卸载

删除插件目录里的 `REDcoLAB.cpm` 与 `REDcoLAB.dll` 即可（见安装脚本列出的路径），然后重启 CSP。本插件不写注册表、不改 CSP 配置、不常驻、不自启。
